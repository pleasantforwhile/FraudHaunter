# Fraud Hunter Bot

Telegram-бот для обучения распознаванию методов телефонного мошенничества.
Разработан в рамках индивидуального итогового проекта учеником 9 класса
ГБОУ школы №469.

## Структура проекта

- `/handlers` — обработчики команд и сообщений
- `/keyboards` — клавиатуры для интерфейса
- `/scenarios` — файлы сценариев для тренажера
- `/database` — работа с базой данных
- `bot.py` — точка входа

## Технологии

- Python 3.11
- aiogram 3.12
- SQLite
